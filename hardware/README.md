# Hardware — Skylog

O projeto eletrônico está concentrado em [skylog/](skylog/README.md).

- [Projeto de desenvolvimento](skylog/projetos/desenvolvimento/skylog.kicad-pedro_sch.kicad_pro): variante com as alterações locais mais recentes.
- [Referência bicamada](skylog/projetos/referencia-bicamada/skylog.kicad_pro): proposta anterior, separada do desenvolvimento.
- [Bibliotecas](skylog/bibliotecas/README.md): símbolos, footprints e modelos associados.
- [Fabricação](skylog/fabricacao/README.md): exportações existentes e seu estado de validação.
- [Documento técnico](../docs/versoes/2026-10-10-2cd5977-local/documentacao-tecnica.md): arquitetura, conexões, materiais e testes.

Abra o arquivo `.kicad_pro` da variante escolhida no KiCad 10. Preserve a pasta
`skylog` inteira ao mover o hardware para outro computador, pois os projetos
compartilham bibliotecas locais. Nenhuma variante foi liberada para fabricação
por esta reorganização.
